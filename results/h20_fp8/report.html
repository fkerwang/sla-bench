本版口径（v7）与审计方法

  1. 每点固定样本、长度八分位蛇形配对、全部回收。每点条数按预热 60 s + 稳态 ≥180 s 且单轮判定窗口 ≥32 条取 8 的整数倍；prompt 按八分位蛇形配对使任意整 block 均值落在 ±1.3% 内；发完后等待全部在途请求返回，杜绝截断慢请求。
  2. 长度达标按被测服务端 /tokenize（即服务端自身 tokenizer）分别核算。以含 PAD_INSTRUCTION 的客户端实际模板长度为 ds_in 基准，要求判定窗口均值与全量均值同时在 ±3% 内、输出均值在 1000 ±3% 内。本报告 61 个测点中 61 个长度达标且零错误、零缺失；每点判定窗口 43–506 条。
  3. 绝对时刻表锁外泊松到达。请求到达时刻在全局单调时刻表上生成，协程在锁外睡眠，速率由 CAT_LOCUST_RATE 独立驱动，彻底消除协调遗漏（Coordinated Omission）；prompt 分词统计移至 SSE 流结束后，不污染 TTFT。窗口实发速率 / 目标速率中位数 1.013（0.84–1.32）。
  4. 稳定性判据（STAB_Z=3）与两档 SLA gap < 10% 自适应加密。窗口按整 block 对半分，TTFT 先线性回归扣除 prompt 长度影响，仅当前后半段均值漂移与中位数漂移同时超阈值（TTFT max(25%, 300 ms)、TPOT max(50%, 10 ms)）且超 3 倍标准误时判排队不收敛。对两档 SLA 边界自动内插补点轮换复测，直至实测最优通过点最短板余量 gap < 10%（或相对跨度 ≤ 2.5% 证实真实台阶悬崖）。
  5. 多档多副本轮换与板间 TPOT 偏差（ms，稳定点相对同速率均值）。
